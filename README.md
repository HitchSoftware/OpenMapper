# OpenMapper

This is an object mapper for .NET. It is based on AutoMapper, version 12.0.1, which was licensed under MIT.

I forked it because I needed something that worked for my projects and didn’t want to deal with license issues.

It’s probably not perfect, but feel free to use it if you like.

---

## Installation

You can install via NuGet (once published):

```

dotnet add package OpenMapper

```

---

## What’s Different?

Not a lot. It's basically AutoMapper v12.0.1 with a new name and license cleaned up.

I plan to keep it working on new versions of .NET. We'll see.
